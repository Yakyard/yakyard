# Code of conduct

Yakyard follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in issues, pull requests, discussions and anywhere else you represent the project.

The short version: be kind, assume good faith, criticize code and not people, and no harassment of any kind.

## Reporting

If someone's behavior is a problem, tell the maintainers privately: use the repository's **Security** tab, **Report a vulnerability**, and start the title with "Conduct:". It's the one private channel GitHub gives every repository. For abusive content on GitHub itself, you can also use GitHub's **Report content**.

Reports are kept confidential. The maintainers will review each one and decide on a response, following the enforcement guidelines in the Contributor Covenant.
